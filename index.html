NASA Lunar Materials Data Integration

M.S. thesis researchUTEP · advisor Prof. Fei XuAug 2026 – present

The project. NASA already holds the lunar materials data researchers need, but it is spread across the Lunar Sample Compendium, regolith simulant reports, and the NASA Technical Reports Server, mostly as PDFs with values buried in text, tables, and plots. The project's goal is one structured dataset that connects each sample's composition and mineralogy to its physical, mechanical, and thermal properties, ready for AI and ML analysis.

My part. My thesis builds the extraction layer that gets the data out of those documents. Text tools and general-purpose LLMs don't read scientific plots reliably, so I'm building a pipeline that does, and that keeps every value traceable to its source.

  • Built a pipeline that goes from papers in to Excel datasets out, available as a web app, a CLI, and an MCP server other agents can call.
  • Reads exact coordinates straight from a PDF's vector layer when it exists (51% of curve figures), and uses OCR and computer vision for raster figures, with a self-check and a visual overlay on every value.
  • Five agents (figure, context, checker, dataset, and an optional LLM) share a per-figure blackboard; the checker sends work back for a stricter re-trace when something looks wrong.
  • Researchers can ask in plain language, such as “mechanical properties of Ti-6Al-4V”, and get values from figures, tables, and text.

89–95%figure detection F1
99% / 86%Ask precision / recall*

69-paper corpus with a frozen 14-paper test set. *Preliminary labels; human verification in progress.

Join-Void Detection in XCT of SiC Nuclear Fuel Cladding

Idaho National Laboratory, TREATMay – Aug 2026First-author manuscript in preparation

Silicon carbide cladding tubes are sealed by bonding an end plug into the tube, and an incomplete bond at that join can become a leak path. Each XCT scan produces thousands of slices, far more than anyone can review by hand.

  • Built an end-to-end pipeline that aligns slices, localizes the join, segments join and void with a two-head ResNet-34 + CBAM + FPN network, and reconstructs candidate 3D leak paths.
  • Enforced the physical rule that voids occur only at the join, both inside the network (join-gated void evidence) and after it (topology filtering).
  • Evaluated with specimen-grouped cross-validation and a written promotion gate, so a model only reaches production when it improves without new false alarms.
